TMTODO-MINI
소개

바탕화면에 붙는 작은 To-Do 위젯. 평소엔 조용히 떠 있고, 제목을 두 번 클릭하면 편집 도구가 나타나요.

기능
체크리스트체크한 항목은 자동으로 맨 아래로
스티커내 투명 PNG로 꾸미기
색상 · 투명도두 색 그라데이션, RGB로 자유롭게
글꼴내 컴퓨터에 설치된 글꼴로 설정
자동 업데이트새 버전이 나오면 위젯에서 알려줘요
설치
  1. 오른쪽 다운로드 버튼으로 zip 받기
  2. 압축 풀기 (압축 안에서 바로 실행 X)
  3. ToDo-mini.exe 더블클릭
  4. 파란 경고창은 추가 정보 → 실행
  5. 오른쪽 아래 트레이(^ 안)에 아이콘이 생겨요
자주 묻는 질문
파란 경고창은 왜 뜨나요?

개인이 만든 앱이라 유료 서명 인증서가 없어서 뜨는 기본 경고예요.

할 일은 어디에 저장되나요?

내 컴퓨터(%APPDATA%\todo-widget)에만 저장되고 어디로도 전송되지 않아요.

업데이트하면 할 일이 사라지나요?

아니요. 할 일, 스티커, 설정은 그대로예요.

위젯이 화면 밖으로 나갔어요

트레이 아이콘 우클릭 → "위젯 위치 처음으로"를 눌러요.

지우려면요?

트레이 아이콘 우클릭 → 종료, 그다음 폴더를 삭제하세요.
