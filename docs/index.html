ToDo-mini

바탕화면에 붙는 작은 To-Do 위젯.
바탕화면을 볼 땐 꾸미고, 작업할 땐 조용히 떠 있어요.

Windows용 다운로드 Windows 10 · 11 / 무료 / 로그인 없음

이런 모습이에요

※ 위 그림은 느낌을 보여주는 예시예요.

기능

  • 체크리스트추가·수정·삭제, 체크한 항목은 자동으로 맨 아래로 내려가요.
  • 자동 층 전환바탕화면에 있으면 바탕화면에 붙고 편집 바가 보여요. 다른 프로그램을 쓰면 맨 위로 올라오고 바는 사라져서, 체크만 눌러져요.
  • 스티커내 투명 PNG 이미지를 붙여서 꾸며요. 위젯 가장자리를 살짝 넘겨도 돼요.
  • 투명 배경배경 투명도를 슬라이더로 조절해요.
  • 글꼴 설정내 컴퓨터에 설치된 글꼴 중에서 골라요.
  • 알아서 업데이트새 버전이 나오면 위젯에 알림 막대가 떠요. 누르면 끝이에요.

설치하는 법

  1. 위의 Windows용 다운로드를 눌러 zip 파일을 받아요.
  2. zip을 압축 풀기 하세요. (압축 파일 안에서 바로 실행하면 안 돼요.)
  3. 폴더 안의 ToDo-mini.exe를 더블클릭해요.
  4. 파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요.
  5. 작업표시줄에는 안 보이고, 오른쪽 아래 트레이(^ 안)에 아이콘이 생겨요. 클릭하면 설정이 열려요.

자주 묻는 질문

파란 경고창은 왜 뜨나요?

개인이 만든 앱이라 유료 서명 인증서가 없어서 뜨는 기본 경고예요. 추가 정보 → 실행으로 넘어가면 돼요.

내 할 일은 어디에 저장되나요?

내 컴퓨터 안(%APPDATA%\todo-widget)에만 저장돼요. 어디로도 전송되지 않아요.

업데이트하면 할 일이 사라지나요?

아니요. 할 일, 스티커, 설정은 그대로 남아요.

위젯이 사라졌어요 / 화면 밖으로 나갔어요

오른쪽 아래 트레이 아이콘을 우클릭 → "위젯 위치 처음으로"를 눌러요.

지우려면요?

트레이 아이콘 우클릭 → 종료 후, 폴더를 삭제하면 돼요.
