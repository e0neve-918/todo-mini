TODO-MINI
소개

화면에 고정할 수 있는 커스텀 To-Do 위젯이에요.
• 스티커와 나만의 색·글꼴로 꾸밀 수 있어요.
• 더블 클릭으로 간편하게 설정을 바꿀 수 있어요.

기능
체크리스트할 일을 끝마치면 바로바로 체크할 수 있어요. 완료된 항목은 자동으로 맨 아래로 내려가요.
간편한 설정더블클릭으로 손쉽게 설정을 수정할 수 있어요.
상단 고정다른 창 위에 항상 떠 있도록 고정할 수 있어요.
자동 업데이트새 버전이 나오면 위젯에서 알려줘요.
커스텀 기능
스티커나만의 사진으로 스티커를 추가하고 꾸며보세요. (배경이 투명한 PNG 이미지 권장)
색상 커스텀두 가지 색상을 자유롭게 선택하여 색상을 커스텀 할 수 있어요.
폰트 커스텀내 컴퓨터에 설치된 폰트로 설정할 수 있어요.
설치
  1. 오른쪽 다운로드 버튼으로 zip 받기
  2. 압축 풀기 (압축 안에서 바로 실행 X)
  3. ToDo-mini.exe 더블클릭
  4. 파란 경고창은 추가 정보 → 실행
  5. 작업 표시줄 오른쪽 시계 옆 ^ 버튼을 누르면 ToDo-mini 아이콘이 보여요
자주 묻는 질문
파란 경고창은 왜 뜨나요?

개인이 만든 앱이라 유료 서명 인증서가 없어서 뜨는 기본 경고예요.

할 일은 어디에 저장되나요?

내 컴퓨터(%APPDATA%\todo-widget)에만 저장되고 어디로도 전송되지 않아요.

업데이트하면 할 일이 사라지나요?

아니요. 할 일, 스티커, 설정은 그대로예요.

위젯이 화면 밖으로 나갔어요

트레이 아이콘 우클릭 → "위젯 위치 처음으로"를 눌러요.

지우려면요?

트레이 아이콘 우클릭 → 종료, 그다음 폴더를 삭제하세요.
