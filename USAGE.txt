To-Do 위젯

[시작하기]
1. 이 폴더를 원하는 곳에 두세요. (예: 문서 폴더)
   ※ 압축 파일 안에서 바로 실행하지 말고 꼭 압축을 풀어 주세요.
2. ToDo-mini.exe 를 더블클릭하세요.
3. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행] 을 누르세요.
   (서명 인증서가 없는 프로그램이라 뜨는 경고예요.)
4. 작업표시줄에는 안 보이고, 오른쪽 아래 트레이(^ 아이콘 안)에 아이콘이 생겨요.
   - 트레이 아이콘 클릭: 설정 열기
   - 트레이 아이콘 우클릭: 설정 열기 / 위젯 위치 처음으로 / 종료

[쓰는 법]
- 아래 칸에 할 일을 쓰고 Enter → 추가
- 글자를 두 번 클릭 → 고치기 / 줄 오른쪽 X → 지우기
- 동그라미를 누르면 완료 (완료한 건 맨 아래로 내려가요)
- 제목(To-Do)을 끌어서 위젯을 옮겨요
- 아래 바: 스티커 넣기 / 배경 투명도 / 항상 위 / 설정
- 스티커: 끌어서 이동, 마우스 휠로 크기, 오른쪽 클릭으로 떼기

[자동 전환]
- 바탕화면을 보고 있으면: 맨 아래층 + 편집 도구가 보여요.
- 다른 프로그램으로 작업 중이면: 맨 위층 + 도구가 숨고, 체크만 눌러져요.
- 설정 → "자동 층 전환"을 끄면 항상 바탕화면 모드로 있어요.

[업데이트]
- 새 버전이 나오면 위젯 위쪽에 파란 "새 버전" 막대가 떠요. 누르면 알아서 바뀌고 다시 시작돼요.
- 설정 맨 아래 "업데이트 확인"으로 직접 확인할 수도 있어요.

[데이터 위치]
%APPDATA%\todo-widget 폴더 안 data.json 에 저장돼요.
지우면 처음 상태로 돌아가요.
