# todo-mini

바탕화면에 붙는 작은 To-Do 위젯 (Windows).

- 바탕화면을 보고 있을 때는 맨 아래층에서 편집 도구가 보이고, 다른 프로그램으로 작업 중일 때는 맨 위층에 떠서 도구가 숨어요.
- 스티커(PNG), 글꼴, 배경 투명도를 바꿀 수 있어요.
- 할 일과 설정은 사용자 컴퓨터 안에만 저장돼요.

## 받기
오른쪽의 **Releases**에서 가장 위 버전의 `ToDoWidget-win64.zip`을 받아 압축을 풀고 `ToDoWidget.exe`를 실행하세요. 자세한 사용법은 압축 안의 `사용법.txt`에 있어요.

## 구성
- `app/` : 시작용 껍데기(거의 안 바뀜)
- `core/` : 실제 앱 코드(업데이트로 바뀌는 부분)
- `.github/workflows/release.yml` : `v0.2.1` 같은 태그를 올리면 자동으로 릴리스 파일을 만들어요
